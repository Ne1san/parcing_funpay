# Skin Pulse — монитор цен FunPay

Локальный сайт запрашивает публичную страницу лотов CS2 и показывает первые 30 актуальных карточек: описание, цену и ник продавца.

## Запуск

1. Откройте терминал в этой папке.
2. Выполните `python server.py` (на некоторых Windows-системах — `py server.py`).
3. Откройте `http://localhost:3000` и нажмите «Получить цены».

Приложение не требует установки библиотек и не хранит данные учётной записи FunPay. Если FunPay ограничит запрос или изменит разметку, в чате появится сообщение об ошибке.

## Публикация на GitHub Pages

Проект можно разместить полностью на GitHub. GitHub Actions раз в 30 минут запускает парсер и публикует свежий файл с лотами вместе с сайтом.

1. Загрузите в репозиторий всю папку проекта, сохранив структуру `public/`, `scripts/` и `.github/workflows/`.
2. В GitHub откройте `Settings → Pages` и выберите **Source: GitHub Actions**.
3. Откройте вкладку `Actions`, выберите workflow **Update FunPay lots and deploy Pages** и нажмите **Run workflow**, чтобы опубликовать сайт сразу.

Кнопка на сайте показывает последний файл `lots.json`, подготовленный Actions. Время обновления отображается рядом с числом лотов.
